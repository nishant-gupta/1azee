# cards-light-withimg

Custom **cards** block: a responsive grid of light cards. Each card has a colored image header, a title, a description, and an optional list of links. It shows 3 columns on desktop, 2 on tablet, and 1 on mobile.

## Authoring (Document Authoring)

Model: `collection`. One row per card, two cells: the image, then the text.

| Cards Light Withimg | |
|---|---|
| (image) | **Cardiovascular, Renal and Metabolism** (Heading 4)<br>Short description.<br>[Heart failure](/…) · [Diabetes](/…) |
| (image) | **Respiratory & Immunology** (Heading 4)<br>Short description.<br>[Asthma](/…) |

- A cell holding only an image becomes the card's image header; any other cell becomes the card body.

## Supported variations

None.
